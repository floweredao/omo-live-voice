## 소개

`omo-live-voice`는 [OmO](https://omo.dev) 데스크톱 앱을 수정하지 않고 열려 있는 세션에 실시간 양방향(full-duplex) 음성 대화를 더해 주는 확장 기능입니다. 한국어로 자연스럽게 말하면 가벼운 인사와 짧은 대화는 `gpt-live-1`(보이스 `cedar`)이 바로 답하고, 코드 작성·파일 확인·명령 실행·테스트 같은 작업 요청은 현재 OmO 세션에 일반 사용자 메시지로 전달합니다. 에이전트가 응답을 마치면 브리지가 코드 블록과 경로를 제외한 핵심 요약을 전달해 `cedar` 목소리로 자연스럽게 읽어 주고, 자세한 코드와 출력은 화면에 그대로 남깁니다.

## 작동 방식

```text
+--------------------------+        WebSocket (127.0.0.1:47831)        +--------------------------+
|        음성 패널         | <=======================================> |       로컬 브리지        |
|  (브라우저 탭, WebAudio) |   24 kHz 모노 PCM16 + JSON 메시지         |     (bridge/main.ts)     |
+--------------------------+                                           +--------------------------+
                                                                            ^                ^
                                                  stdio JSON 라인           |                | WSS (wss://api.openai.com/v1/live/sessions)
                                                  (발화, 상태, 스트리밍     |                | 24 kHz PCM16, 클라이언트 위임,
                                                   델타, 에이전트 질문)     v                v 코멘터리, 사용량
                                                                       +--------------------------+   +--------------------------+
                                                                       |       OmO 익스텐션       |   |     OpenAI GPT-Live      |
                                                                       |   (extension/index.ts)   |   |  model: gpt-live-1       |
                                                                       |  /voice + voice_start    |   |  voice: cedar            |
                                                                       +--------------------------+   +--------------------------+
```

1. **OmO 익스텐션(`extension/index.ts`)**: OmO 세션에 `/voice` 슬래시 명령어와 `voice_start` 도구를 등록합니다. 음성을 시작하면 `bridge/main.ts` 프로세스를 띄우고 단일 세션 잠금 파일(`~/.omo-live-voice/active.json`)을 잡은 뒤 브라우저 탭으로 음성 패널을 엽니다(OmO 2026.1030.1에서는 MCP App 사이드패널이 렌더링되지 않아 브라우저 탭을 기본으로 사용합니다).
2. **로컬 브리지(`bridge/main.ts`)**: macOS 로그인 키체인에서 OpenAI API 키를 읽어 `wss://api.openai.com/v1/live/sessions`에 모델 `gpt-live-1`, 보이스 `cedar`로 연결하고, 실행할 때마다 새로 만드는 랜덤 토큰과 Origin 검증으로 보호되는 로컬 패널 서버(`http://127.0.0.1:47831`)를 엽니다.
3. **클라이언트 위임과 음성 요약 응답**: 인사나 짧은 잡담은 `gpt-live-1`이 즉시 대답합니다. 파일 조회, 코드 수정, 테스트 실행처럼 프로젝트 확인이 필요한 말은 `session.delegation.created` 이벤트를 통해 OmO 세션으로 전달됩니다. 브리지는 짧은 접수 안내("네, 확인해 볼게요" 등)를 들려준 뒤 에이전트가 작업을 끝내면 코드·인라인 코드·URL·경로를 덜어낸 한국어 요약문을 `session.commentary.append`로 보내 음성으로 읽어 줍니다.
4. **끼어들기(Barge-in)와 작업 취소**: 어시스턴트가 말하는 도중 사용자가 400 ms 이상 말하면 패널 재생 버퍼를 즉시 비우고 발화를 멈춘 뒤 사용자의 말을 끝까지 듣습니다. 에이전트가 작업 중일 때 `"그만"` 또는 `"취소"`라고 말하면 진행 중인 턴을 중단합니다.
5. **에이전트 질문 낭독**: 에이전트가 `ask_user_question` 도구로 선택형 질문을 띄우면 패널에 질문 카드가 나타나고, 브리지가 제목·질문·번호별 선택지를 코멘터리 청크로 나누어 `cedar`가 순서대로 읽어 줍니다. OmO 익스텐션 API에는 질문에 응답을 제출하는 인터페이스가 없으므로, 최종 선택은 OmO 화면에서 클릭해 답합니다.

## 요구 사항

- **macOS 15 이상** (Apple silicon, macOS 27.2에서 검증).
- **OmO 데스크톱 >= 2026.1030.1** 및 내장 런타임 **senpi 2026.10.27-1**.
- **Bun >= 1.4** (Bun 1.4.4에서 검증).
- **OpenAI 플랫폼 API 키** (과금 크레딧이 활성화된 상태이며 `gpt-live-1` 접근 권한이 있는 키).
- **macOS 한국어 `Yuna` 시스템 음성** (`scripts/qa/make-fixtures.sh`로 QA 테스트용 WAV 픽스처를 다시 만들거나 `OLV_DOCTOR_QA=1 scripts/doctor.sh`를 실행할 때만 필요하며, 평소 음성 대화에는 필요하지 않습니다).

## 설치 방법

저장소를 클론한 뒤 macOS 키체인에 OpenAI API 키를 저장하고 설치 스크립트를 실행합니다. 빌드된 패널 에셋(`panel/dist/`)은 저장소에 커밋되어 있지 않으므로 `scripts/install.sh`가 의존성 설치, 패널 빌드, OmO 익스텐션 등록을 한 번에 처리합니다.

```sh
git clone https://github.com/floweredao/omo-live-voice.git
cd omo-live-voice

# 1. macOS 로그인 키체인에 OpenAI API 키 저장 (서비스 이름: openai-live-api-key)
scripts/set-key.sh
# 또는 터미널에 노출하지 않고 클립보드에서 바로 저장:
# pbpaste | scripts/set-key.sh

# 2. 의존성 설치, panel/dist 빌드 및 OmO 익스텐션 등록
scripts/install.sh

# 3. 로컬 설치 상태와 호환성 기준선 점검
scripts/doctor.sh
```

설치가 끝나면 OmO에서 **새 세션**을 열고 `/voice`를 입력합니다. (OmO 입력창에서 `/voice`만 치고 첫 번째 `Enter`를 누르면 슬래시 명령 자동완성이 선택되므로 `Enter`를 한 번 더 눌러 실행하세요.)

## 사용법

### 슬래시 명령어와 에이전트 도구

| 명령어 / 도구 | 설명 |
| --- | --- |
| `/voice` | 현재 세션에서 음성 모드를 시작하고(가드로 일시정지된 경우 재개) 브라우저에 음성 패널을 엽니다. |
| `/voice tab` | 브라우저 탭으로 음성 패널을 다시 엽니다. |
| `/voice confirm on` | 인식된 발화를 에이전트에 바로 보내지 않고 패널에 초안 카드로 띄워 확인 후 보내도록 설정합니다. |
| `/voice confirm off` | 인식된 발화를 확인 단계 없이 바로 에이전트에 보냅니다(기본값). |
| `/voice stop` | 음성 모드를 종료하고 GPT-Live 연결과 브리지 프로세스를 정리한 뒤 세션 잠금을 해제합니다. |
| `voice_start` (도구) | 에이전트가 현재 세션의 음성 모드를 시작할 때 호출하는 도구로, `/voice`와 똑같이 동작합니다. |

한 번에 하나의 OmO 세션만 음성 브리지를 사용할 수 있습니다. 다른 세션에서 이미 음성이 켜져 있으면 어느 세션이 연결되어 있는지 안내하며, 해당 세션에서 먼저 `/voice stop`을 실행해야 합니다.

### 음성 패널 조작과 단축키

브라우저 탭으로 패널이 열리면 화면을 한 번 클릭하거나 아무 키나 눌러 브라우저 오디오 캡처를 활성화하고 마이크 권한을 허용해 주세요.

- **음소거 / 음소거 해제(`음소거` / `음소거 해제`)**: 버튼을 누르거나 단축키 `Space` 또는 `M`(`ㅁ`)을 눌러 마이크를 켜고 끕니다.
- **중지(`중지`)**: `중지` 버튼을 누르거나 `Escape` 키(확인 창 표시)를 누르면 `/voice stop`과 동일하게 음성 세션을 완전히 종료하고 브리지를 닫습니다.
- **재개(`재개`)**: 유휴 시간 초과나 시간 한도로 일시정지된 상태에서 누적 시간과 예상 비용을 확인하며 GPT-Live 연결을 다시 엽니다.
- **초안 보내기 / 취소(`보내기` / `취소`)**: `/voice confirm on` 상태일 때 `Enter` 키를 누르거나 `보내기` 버튼을 클릭하거나 `"보내"`·`"전송"`이라고 말하면 전송되고, `취소` 버튼을 누르거나 `"취소"`·`"지워"`라고 말하면 초안을 버립니다.
- **다시 연결(`다시 연결`)**: 로컬 브리지와의 WebSocket 연결이 끊어졌을 때 한 번 다시 연결을 시도합니다.
- **오디오 기기 선택(`마이크` / `스피커`)**: 사용할 마이크와 스피커를 즉시 바꿀 수 있으며, 선택한 기기 이름은 다음 세션에도 유지됩니다.

## 비용 가드(Cost Guard)

GPT-Live(`gpt-live-1`)는 연결된 시간 기준으로 **분당 약 $0.05**가 과금됩니다. 탭을 열어 둔 채 자리를 비워 요금이 계속 나가는 일을 막기 위해 브리지가 자동으로 가드를 적용합니다.

- **실시간 예상 비용 표시**: 패널 오른쪽 위 배지에 누적 연결 시간과 예상 비용(`MM:SS · 예상 $X.XX`)이 1초마다 갱신됩니다.
- **3분 유휴 자동 종료**: 사용자 발화와 에이전트 작업이 모두 없는 상태로 3분(`180,000 ms`)이 지나면 브리지가 GPT-Live WebSocket 연결을 닫아 분당 과금을 멈춥니다. 다시 이야기할 준비가 되면 패널의 `재개` 버튼을 누르거나 `/voice`를 실행하세요.
- **55분 경고 및 60분 상한**: 누적 연결 시간이 55분에 이르면 패널에 경고를 띄우고, 60분에 도달하면 연결을 자동으로 닫습니다. 사용자가 직접 재개하면 예산 타이머가 새로 시작됩니다.
- **일시적 끊김 1회 자동 재연결**: 대화 중이거나 에이전트가 작업 중일 때 상위 WebSocket이 끊기면 최근 대화 10줄을 문맥으로 넣어 한 번 자동 재연결합니다. 30초 이상 조용한 상태에서 끊겼거나 재연결까지 실패하면 사용자가 다시 재개할 때까지 닫힌 상태를 유지합니다.

## 개인정보와 데이터 저장

- **API 키는 키체인에만 보관**: `scripts/set-key.sh`는 macOS 로그인 키체인의 `openai-live-api-key` 서비스 항목에만 API 키를 저장합니다. `bridge/main.ts`가 `/usr/bin/security`로 직접 읽어 쓰며, 키는 브라우저 패널로 전달되거나 파일로 기록되지 않습니다. 모든 브리지 로그는 저장 전에 마스킹 함수(`redact`)를 거쳐 `sk-...`, `Bearer ...`, URL `?token=...` 값을 `[redacted]`로 가립니다.
- **로컬 런타임 폴더(`~/.omo-live-voice/`)**: 권한 `0700`으로 생성됩니다.
  - `~/.omo-live-voice/transcripts/<ISO-타임스탬프>.md`: 실제 대화가 오갔을 때만 생성되는 마크다운 대화 기록입니다.
  - `~/.omo-live-voice/logs/<ISO-타임스탬프>.log`: 민감 정보가 마스킹된 JSONL 브리지 로그(최신 20개 유지)와 `ext-<ISO-타임스탬프>.log` 익스텐션 로그입니다.
  - `~/.omo-live-voice/settings.json`: 선택한 마이크·스피커 기기 이름을 저장합니다.
  - `~/.omo-live-voice/active.json`: 음성 모드가 켜져 있는 동안 활성 세션 ID와 브리지 PID를 기록하는 임시 잠금 파일입니다.

## 알려진 제약 사항

- **에이전트 질문은 화면에서 선택**: 에이전트가 `ask_user_question`으로 객관식 질문을 던지면 `cedar`가 질문과 선택지를 읽어 주고 패널에도 카드가 표시되지만, OmO 익스텐션 API 제약으로 음성으로 선택지를 제출할 수는 없습니다. 답변은 OmO 화면에서 클릭해 선택해 주세요.
- **질문 문장 표현이 간혹 살짝 바뀜**: 번호가 매겨진 선택지 본문은 순서대로 읽지만, `gpt-live-1`이 질문 문장의 서술어를 간혹 다듬어 읽을 때가 있습니다(예: `"어떤 순서로 진행할까요?"`를 `"어떤 순서로 할까요?"`로 발화). 정확한 문구가 중요할 때는 화면의 질문 카드를 함께 확인해 주세요.
- **인라인 코드 제거로 인한 조사 남음**: 음성 어댑터가 기호나 코드 조각을 그대로 읽지 않도록 `commentary.append` 전송 전에 인라인 코드를 제거하는데, 이 과정에서 코드 뒤에 붙어 있던 한국어 조사만 남는 경우가 간혹 있습니다.
- **브라우저 탭 패널 사용**: OmO 2026.1030.1에서 MCP App 사이드패널이 표시되지 않아 `/voice` 실행 시 기본 브라우저 탭으로 음성 패널이 열립니다.

## 문제 해결(Troubleshooting)

- **마이크 권한 거부(`마이크 권한이 거부되었어요`)**: 브라우저 사이트 설정에서 `127.0.0.1`의 마이크 권한을 허용하고, macOS **시스템 설정 > 개인정보 보호 및 보안 > 마이크**에서 사용 중인 브라우저가 켜져 있는지 확인하세요. 또한 브라우저 오디오가 켜지도록 열린 패널 화면을 한 번 클릭해야 합니다.
- **`cedar` 보이스 거절(`GPT-Live가 cedar 보이스를 거절했어요`)**: `omo-live-voice`는 `cedar` 보이스만 사용합니다. 키체인에 저장한 OpenAI API 키가 `gpt-live-1` 모델과 `cedar` 보이스 권한이 있는 조직·프로젝트 키인지, 결제 크레딧이 남아 있는지 확인하세요.
- **사이드패널이 열리지 않을 때**: OmO 2026.1030.1에서는 사이드패널 대신 브라우저 탭으로 열립니다. 실수로 탭을 닫았거나 창이 뜨지 않았다면 세션에서 `/voice tab`을 실행해 다시 여세요.
- **다른 세션에 이미 연결되어 있다고 나올 때(`이미 다른 세션에 연결됨`)**: 안내된 세션에서 `/voice stop`을 실행하거나 열려 있는 음성 패널에서 `중지`를 누르세요. 이전 브리지 프로세스가 이미 종료된 경우에는 `/voice`를 다시 실행하면 남은 `~/.omo-live-voice/active.json` 잠금 파일을 자동으로 정리합니다.
- **QA 픽스처 생성 시 `Yuna` 음성이 없다고 나올 때**: `scripts/qa/make-fixtures.sh`는 테스트용 WAV 파일을 만들 때 macOS 한국어 음성 `Yuna`를 사용합니다. **시스템 설정 > 손쉬운 사용 > 콘텐츠 말하기 > 시스템 음성 > 음성 관리 > 한국어 > Yuna**를 내려받은 뒤 `bun run fixtures`를 다시 실행하세요. 일반 `/voice` 사용에는 `Yuna`가 필요하지 않습니다.

## 제거 방법(Uninstall)

```sh
scripts/uninstall.sh
```

`scripts/uninstall.sh`는 OmO에서 익스텐션 등록을 해제하고 `~/.omo-live-voice/active.json`을 지웁니다. `~/.omo-live-voice/` 안의 대화 기록·설정 파일과 키체인의 API 키는 그대로 남겨 두므로, 완전히 삭제하려면 `rm -rf ~/.omo-live-voice` 및 `security delete-generic-password -s openai-live-api-key`를 직접 실행하세요.
