# Compatibility

The tested baseline is:

| Component | Tested version |
| --- | --- |
| OmO | 2026.1030.1 |
| senpi runtime | 2026.10.27-1 |
| Bun | 1.4.4 |
| macOS | 27.2 |

Run `scripts/doctor.sh` after installation to check local prerequisites and
compatibility. Other versions may work but have not been tested.
